# Ejemplos de código

Estos archivos conservan los algoritmos de montaje, mezcla, comparación, reconstrucción vectorial y animación. Las carpetas se renombraron y el texto de ejemplo se desidentificó para publicación.

- `demo_montaje_v4`: generador de montaje y timeline de una muestra vertical.
- `demo_integracion`: montaje con recursos y transformaciones por componentes.
- `demo_produccion`: mezcla que conserva la voz y comparación visual por fotograma.
- `arquitectura_motion_3s`: construcción y timeline GSAP de una prueba técnica.
- `clone_componente`: construcción estática, animación, contornos, render y comparación.

Los originales, grabaciones de cámara, audio, transcripciones, capturas de referencias, fuentes comerciales y entregables no se distribuyen. Tampoco se incluyen HTML o bundles compilados que incrustaban esos recursos. Algunos scripts requieren preparar un `proyecto.json` local, un SVG de base propio y recursos con los nombres que indican; no son demos listas para renderizar sin entradas. Los datos JSON de pruebas son sintéticos.

Las rutas `proyectos/` están reservadas al trabajo local generado. Las operaciones de Drive requieren configurar referencias propias y una cuenta autorizada; el repositorio no contiene conexiones operativas de cuentas existentes.
